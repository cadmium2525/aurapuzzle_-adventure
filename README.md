# オーラコネクト・バトル

オーラ(玉)をつないで消し、仲間と共にダンジョンを攻略するブラウザ/PWA のパズルRPG。
ビルド不要の静的サイトで、ES Modules をそのまま読み込んでいる。

## ディレクトリ構成

```
.
├── index.html              画面の骨組み(DOM)のみ。ロジックは持たない
├── manifest.json           PWA マニフェスト
├── sw.js                   Service Worker(アプリ本体は network-first)
├── assets/icons/           アプリアイコン
└── src/
    ├── css/style.css       全画面のスタイル
    └── js/
        ├── main.js         エントリポイント。初期化と画面登録
        ├── core/
        │   ├── storage.js  localStorage ラッパー
        │   ├── state.js    セーブデータ / 編成 / スタミナ / ランク
        │   ├── nav.js      画面遷移とトップバー
        │   ├── sysmodal.js ⚙ システムモーダル(音量・リタイア)
        │   ├── ui.js       toast などの汎用ユーティリティ
        │   ├── firebase.js Firebase SDK の遅延読み込み
        │   └── friends.js  フレンド機能とクラウド保存
        ├── data/
        │   ├── characters.js オーラ / キャラクター / NPCサポート
        │   ├── skills.js     リーダースキル / スキル
        │   └── gamedata.js   ステージ・ショップ・ガチャ・各種定数
        ├── battle/
        │   ├── board.js    盤面データ操作(生成 / 連結判定 / 落下 / 補充 / 変換)
        │   ├── party.js    出撃パーティ組み立てとリーダースキル合成
        │   ├── renderer.js Canvas 描画
        │   └── battle.js   ダンジョン進行とバトル制御
        └── screens/        home / dungeon / character / gacha / shop /
                            mypage / friends / guide
```

依存の向きは `screens・battle → core → data` の一方向。
`nav.js` は画面の描画関数を `registerScreen()` で受け取るだけなので、
画面モジュールと相互参照しない。

## ゲームの主なルール

### 編成は「人物」4人
自陣は**人物キャラクター3人**(先頭がリーダー)と、ダンジョン出発時に選ぶ
**サポート1人**の計4人。サポートはフレンドの貸し出しキャラに加えて、
**NPCサポート**をいつでも選べる(フレンドがいなくても困らない)。
NPCサポートはプレイヤーランクで順次解放される。

### オーラ
オーラは4色。🔥火 / 💧水 / 🌿木 / 💗癒。癒は攻撃ではなく**回復**を担当する。
盤面は7列×8行、同じオーラが**4つ以上**つながると消滅する。

### キャラクターごとの攻撃
- 各キャラクターは固有のオーラを持つ。
- **自分のオーラを消したときだけ攻撃する**。消さなかったキャラは攻撃しない。
- 消した数が多いほど、そのキャラの攻撃力が上がる。
- 癒オーラのキャラは攻撃のかわりにパーティを回復する。
- 編成した4人がそれぞれ個別に敵を攻撃する(ダメージもキャラごとに表示)。

### 操作時間は10秒
最初にオーブへ触れてから**10秒**。指を離しても時間内なら何度でも掴み直せる。
時間が切れると自動的に手番が確定する。この10秒を**リーダースキルとスキルで
延ばして戦う**のが戦術の中心になる(上限40秒)。

### リーダースキル
発動するのは**自陣リーダー(編成1人目)**と**サポート**の2つ。
効果は `src/js/data/skills.js` に定義していて、次の種類がある。

| 効果 | 例 |
| --- | --- |
| オーラ別の攻撃倍率 | 業火の覇者「火オーラ2.2倍・操作時間+2.0秒」 |
| 全オーラの攻撃倍率 | 大聖女の福音「全オーラ1.4倍・回復2.0倍・操作時間+2.0秒」 |
| 操作時間の延長 | 氷結の思考「オーラ操作時間+3.0秒」 |
| 最大HP / 回復力 | 聖騎士の盾「最大HP1.5倍・被ダメージ15%減」 |
| コンボ条件 | 風読みの極意「5コンボ目以降の攻撃力1.8倍」 |
| 連結条件の緩和 | 世界樹の恵み「連結3個で消えるようになる」 |

### スキル
バトル中に仲間をタップして発動。ターン経過でチャージされる(CT)。
操作時間の延長、回復、固定ダメージ、オーラ変換、盤面シャッフル、
攻撃力アップ、被ダメージ軽減、敵の攻撃遅延などがある。

### ダンジョン / スタミナ / ランク
- 1ステージ5フロア。フロアは**自動で進み**、フロア間の回復はない。
- 敵は一定ターンごとに攻撃してくる(ボスは毎ターン)。
- スタミナは3分で1回復。初期ダンジョンの消費は5。
- ステージクリアで EXP を獲得。**ランクアップ時は「現在のスタミナ +
  ランクアップ後の最大スタミナ」になる**ので、スタミナは最大値を超えて
  オーバーフローする(超過ぶんは自然回復では減らない)。

## 開発

ES Modules を使うため `file://` では動かない。ローカルでは HTTP で配信する。

```sh
python3 -m http.server 8000
# → http://localhost:8000/index.html
```

セーブデータは `localStorage` の `acb_state` キー(現行 `version: 5`)。
旧フォーマット(5属性 / モンスター編成)は起動時に自動で移行される。
旧モンスターは同じオーラ・レアリティの人物キャラクターへ読み替えられ、
旧 光/闇 は癒(ピンク)へ集約される。

## フレンド機能 / クラウド保存(Firebase)

Firebase は**設定済みのときだけ**動的 import で読み込むため、未設定でも
オフラインでもゲーム本体(ローカル保存)はそのまま遊べる。

`src/js/core/firebase.js` の `firebaseConfig` を、ご自身の Firebase プロジェクトの
設定値に置き換えると有効になる。

1. Firebase コンソールでプロジェクトを作成
2. Authentication → Sign-in method で「匿名」を有効化
3. Firestore Database を作成(本番モードでOK)
4. 下記のセキュリティルールを設定(簡易的な公開ルール。運用時は要調整)

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read: if true;
      allow write: if request.auth != null;
      match /friends/{friendId} {
        allow read: if true;
        allow write: if request.auth != null;
      }
      match /save/{doc} {
        allow read, write: if request.auth != null && request.auth.uid == uid;
      }
    }
    match /friendCodes/{code} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```

5. `firebaseConfig` にプロジェクトの設定値(apiKey等)を貼り付け

### フレンドでできること
- マイページで発行される「フレンドコード」を交換して友達を登録する
  - フレンド登録時: 自分+300フレポ、相手+300フレポ
  - 毎日1回の「あいさつ」: 自分+20フレポ、相手+10フレポ
- マイページの「貸し出しキャラクター」で1人を指定すると、フレンドの
  ダンジョン挑戦時にサポート枠として借りられる(リーダースキルも発動する)
