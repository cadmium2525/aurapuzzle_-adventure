# 敵マスターと特殊ダンジョンの出現管理

- 敵の名前・画像・行動・攻撃間隔は `src/js/data/enemy-master.js`（管理ツールで追加した敵は `custom.js`）に置く。
- テクニカルは10階層ごと、曜日は7曜日ごとに5体の明示出現表を持つ。管理ツールの「出現管理」で変更すると `CUSTOM_SETTINGS.specialEncounters` に保存される。新規敵を登録しただけでは、この2種には登場しない。テクニカルの各階層内では、ステージごとに5体の登場順をずらす。
- 降臨・イベントは各フロアに敵IDを明示する。戦闘用の敵データは `spawnEnemy()` から組み立て、技をフロアごとに複製する。
- ノーマルだけは従来どおり一般敵プールから自動配置する。ボスはプールから除外する。
- 特殊ダンジョンのHP・攻撃力はステージ難度で変えてよいが、攻撃間隔と技は敵マスターから取得する。同じ敵IDで別の技を使わせたい場合は、見た目・名前も区別できる別IDを登録する。

## 追加アートの生成記録

5点とも画像生成スキルの built-in `image_gen` で、各アセットを別々に生成。共通指定は「高品質な和製ファンタジーパズルRPGの非ボス敵、全身を画面中央に収める、モバイル戦闘画面でも識別できる、塗りのあるアニメ調、透明背景・きれいなアルファ、背景・床・文字・UI・透かしなし、既存の幽霊・狼・蜂・竜・人魚・キノコ・岩巨人・ワーム・ロボットと似せない」。それぞれの個別プロンプトは次のとおり。

| ID | 個別の生成指示 | 固有行動 |
|---|---|---|
| `glyphowl` | 琥珀の目、蒼と古金の羽、L字の幾何学文様が刻まれた羊皮紙のような翼を大きく広げる守護梟。正面寄りの3/4ポーズ。 | L字形状ガード2ターン |
| `umbrastag` | 濃藍の鹿。大きな三日月状の枝角、角先と蹄だけ紫・青緑の幽光、角の間にオーラ拘束の輪。四足の鹿らしい輪郭。 | 水オーラバインド2ターン |
| `chronosnail` | 真珠銀の巻貝。大きな透明な螺旋貝殻は砂時計形で、金色と青緑の時砂が流れる。殻には真鍮の時計機構、頭に表情のある2本の眼柄。 | 操作時間6秒固定2ターン |
| `mirrorjelly` | 人型でない浮遊する海月。オパールの鏡面を多面体状にした傘、長く繊細な半透明の触手、銀・深海青・青緑の虹彩。 | 水オーラ吸収3ターン |
| `arcanacauldron` | 自律して動く黒鉄と真鍮の魔法薬釜。丸い釜、三本の鉤脚、三日月状の取手、正面のいたずら顔の仮面、青緑と桃紫の薬液と湯気。魔女本人は描かない。 | 水・闇オーラ吸収3ターン |

元のアルカナ画像を編集元として、画像生成スキルの built-in `image_gen` で以下の色違いを作成した。生成指示の共通部分は「元画像の魔法薬釜と同じシルエット・3本脚・三日月の取手・いたずら顔の仮面・3/4構図・アニメ調を維持し、薬液・煙・目・宝石・反射色だけを変更する。透過背景のバトル用切り抜き。背景・床・別キャラクター・文字・UI・透かしは付けない」。各PNGは透過を保って最大1024pxのWebPに変換した。

| ID | 追加の色指定 | 固有行動 |
|---|---|---|
| `arcanacauldron_fire` | 赤・朱色・溶岩色の薬液と煙。火属性と一目で分かる。 | 火オーラ吸収3ターン |
| `arcanacauldron_wood` | エメラルド・葉緑・ライム色の薬液と煙。木属性と一目で分かる。 | 木オーラ吸収3ターン |
| `arcanacauldron_heal` | 薔薇・桜色・象牙白の薬液と煙。癒属性と一目で分かる。 | 癒オーラバインド3ターン（癒を消せない） |

火・木の色違いはテクニカル第5階層「吸収の試練」、癒の色違いは第3階層「束縛の試練」に配置した。曜日ダンジョンにも属性に対応する月・火・木曜日に明示配置した。元のアルカナと色違いはそれぞれ別IDで、どのステージでも行動は敵マスターに従う。

生成されたPNGの透過を維持して、ゲーム用に最大1024pxのWebPへ変換した。生成元は Codex の `generated_images` に残し、実装が参照する最終アセットは `assets/enemy/` に置いた。
