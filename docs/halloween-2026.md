# ハロウィンパーティ 2026

## 開催設定

- 日本時間 2026/10/1 00:00 ～ 2026/10/31 23:59:59（終了境界は11/1 00:00）。
- 管理ツールの「イベント」で期間・公開状態・交換素材・交換商品を編集。
- キャラ／ダンジョンのイベントIDに `halloween_2026` を指定。個別の公開期間とイベント期間の両方を満たす場合のみ入手・入場可能。
- 終了後も獲得済みキャラ・進化・所持キャンディは保持。ガチャ、ダンジョン入場、交換所のみ閉じる。
- 日時はクライアント時計による判定。時計改変を防ぐサーバー権威の期間制御ではない。

## イラストと管理ツール経路

既存キャラを参照してImageGenで進化前後10枚を生成。管理ツールのキャラ画面から取り込み、WebP変換と顔アイコン切り出しを実施。管理ツールのアトラス生成・リリース機能で登録。

- 本体: `assets/chars/hw_{kai,mio,noa,rune,kyuko}_{1,2}.webp`
- アイコン: 同じ名前の `_icon.webp`（計10枚）
- アトラス: `assets/chars/char_atlas.webp` と `src/js/data/char-atlas.js`
- 交換素材: `assets/items/halloween_candy.webp`
- バナー: `assets/promo/halloween_2026.webp`
- コンテンツの正本: 管理ツール生成の `src/js/data/custom.js`（手編集しない）

### 再制作時のプロンプト要点

全キャラ共通: 元キャラの顔・髪色・個性を維持。高品質な日本のファンタジーRPGイラスト、透明背景、全身と装飾を画角内、正方形、文字や枠なし。進化後は同一人物の衣装と魔法演出を豪華にする。

- カイ: 黒と深紅の吸血鬼貴族マント、氷の剣。進化後は冠と氷の蝙蝠翼。
- ミオ: 紺と白のヴィクトリア風幽霊姫、氷のランタンと小さな幽霊。進化後は霊的な女王と霜の竜。
- ノア: 上品なエメラルド色の長い魔女ドレス、尖り帽子、金の秋葉、魔法書と箒。進化後は巨大な魔導書と緑の魔法陣、翼のある南瓜。
- ルネ: オレンジ・黒・金の南瓜女王ドレス、南瓜の冠と杖。進化後は南瓜の玉座と炎の翼。
- キュウコ: 成人の銀髪・琥珀眼の狐姫、紫・橙・黒の着物、ジャックオーランタン、ロリポップと菓子籠。進化後は九尾を広げた威厳ある座り姿。
- キャンディ: 橙と紫の包み紙、金の南瓜顔、一個だけ、32pxでも判別できる形、透明背景。
- バナー: 左にカイ、右にキュウコ、紫の城と橙の南瓜、金の装飾。「ハロウィンパーティ」「10/1 ▶ 10/31」「キャンディを集めて限定キュウコと交換！」。
